# 岁美银龄 · 网站练习项目

这是基于原始 `index.html`、`style.css`、`script.js` 扩展的静态网站。已保留原有 Header / Hero / Footer 布局及轮播基础，并补齐关于、课程、活动、联系四个页面。

## 使用

使用 VS Code 打开整个文件夹，用 Live Server 打开 `index.html`；或直接打开 `index.html`。部署时将整个文件夹内的内容上传到 GitHub 仓库根目录，在 Settings → Pages 中选择 main / (root)。

## 图片

`images/suimei1.jpg` ~ `suimei3.jpg` 是本项目制作的演示插画，并非真实活动照片。可以直接替换为同名的、具有使用权限的照片，轮播会自动读取。

## 注意

本项目为**非官方网站 / 个人学习展示**。课程类别和页面文案属于设计示例，不代表品牌现行服务信息。留言表单不上传、发送或存储数据。如用于真实机构官网，需根据官方提供的名称、地址、课程及授权素材修改。
